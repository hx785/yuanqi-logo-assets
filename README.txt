二、标准字体规范 (Brand Typography)
--------------------------------------------------------------------------------
1. 中文标准字体:
   - 官方首选: 汉仪旗黑 65S / 思源黑体 (Source Han Sans SC Medium / Bold)
   - 系统安全替代: 苹方 (PingFang SC Regular / Medium) / 微软雅黑 (Microsoft YaHei) / HarmonyOS Sans

2. 英文标准字体:
   - 官方首选: Montserrat (SemiBold / Bold) / Inter (Medium / SemiBold)
   - 商业与印刷替代: Helvetica Neue (Medium) / Arial (Bold)


三、最小使用尺寸规范 (Minimum Size)
--------------------------------------------------------------------------------
为确保在各种介质上的辨识度与印刷精度，严禁低于以下极限尺寸：
1. 横版 / 标准组合 Logo:
   - 屏幕端: 宽度不得小于 120 px
   - 印刷端: 宽度不得小于 25 mm

2. 纯图标版 (Icon):
   - 屏幕端: 宽度/高度不得小于 16 px (Favicon 极限尺寸)
   - 印刷端: 尺寸不得小于 5 mm × 5 mm


四、安全留白规范 (Clear Space)
--------------------------------------------------------------------------------
为维护品牌视觉形象的独立性与庄重感，Logo 周围必须保留不可侵犯的保护区域。
任何其他图形、文字、边框均不得进入此安全区。

【留白标准计算方式】：
以 Logo 中纯图标元素的高度 H 为基准，四周预留的最小空间为：
  X ≥ 1/4 H (0.25 H)

【安全区示意图】：
   +-----------------------------------------------+
   |                      X                        |
   |     +-----------------------------------+     |
   |     |                                   |     |
   |  X  |      [ 图标 ]    元企科技         |  X  |
   |     |               YUANQI TECH         |     |
   |     |                                   |     |
   |     +-----------------------------------+     |
   |                      X                        |
   +-----------------------------------------------+
   (其中 X 为四周最小留白空间，至少等于 Logo 图标高度的 1/4)


五、Logo 严禁与禁用行为 (Incorrect Usage)
--------------------------------------------------------------------------------
任何人在任何媒介中应用 Logo 时，严禁出现以下篡改行为：
1. 严禁拉伸变形：不得单向拉伸或压缩改变原宽高比例。
2. 严禁随意改色：不得擅自将品牌蓝变更为绿、红、黄等未授权颜色。
3. 严禁添加描边与杂乱特效：禁止为 Logo 添加描边、强浮雕、发光或杂乱投影。
4. 严禁旋转角度：Logo 必须水平放置，禁止任何角度的倾斜或颠倒。
5. 严禁复杂背景压图：不得在对比度低、花哨或有强噪点的复杂图案背景上直接放置 Logo。
   （遇深色或复杂背景时，必须使用白色反白款并保证充足对比度）。
6. 严禁擅自改变排版：不得随意调整图形与中英文字标的相对比例与间距。
